# Probe 简报：验证子代理的**行为**是否适合本流程

> 本 probe 只测行为，不测环境。环境能力由父代理用 `envcheck.sh` 单独验证——子代理与父代理同 uid、同环境，不需要通过它来测解释器是否存在。

## 任务

1. 新建文件 `probe.txt`，内容为一行：`ok`
2. **提交**到 `main`（不要新建或切换分支），提交信息任意

## 硬性要求

- 只允许改动 `probe.txt`，不得新建或修改其他任何文件
- 必须提交（`git status` 必须为空）
- 不得执行 `amend` / `reset` / `rebase` / `stash` / `worktree`
- 不需要、也不得调用任何解释器或外部依赖

## 通过标准

`postflight` 判定为 `pass`。验收命令用 `test -f probe.txt`（shell 内建，零依赖）。

## 说明

这是行为探测，不是真实任务。它检查四件事：

| 检查 | 失败说明 |
|---|---|
| 文件建在白名单内 | 不守路径边界 |
| 已提交 | 不理解"交付=提交" |
| `stopReason=completed` | 回合异常结束（如 token 耗尽） |
| 验收命令退出 0 | 无法产出可验证结果 |

任何一项不达标都说明该模型不适配本流程——它不会因为任务变大而变好。
